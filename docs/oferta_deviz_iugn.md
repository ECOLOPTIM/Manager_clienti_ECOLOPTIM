# Deviz-oferta IUGN

Devizul-oferta este un singur document, cu un singur numar si o singura data.
Formularul contractului cere aceste date o singura data. Optiunea pentru deviz separat a fost eliminata.
Variabilele vechi nr_oferta/data_oferta si nr_deviz/data_deviz primesc aceeasi referinta la salvare si generare.
O ciorna veche cu referinte distincte afiseaza un avertisment pentru verificare; contractele deja emise raman nemodificate.
O ciorna care are numai referinta devizului o recupereaza integral in campurile comune.

Devizul-oferta trebuie emis sau incarcat in dosar; preluarea referintei nu creeaza si nu ataseaza automat documentul lipsa.
Sablonul instalat este adaptat la generare pentru denumirea „Deviz-oferta”; nu necesita reinstalare.
