# Oferta folosita ca deviz IUGN

Implicit, contractul foloseste numarul si data ofertei acceptate si nu cere un deviz suplimentar.
Bifati „Exista un deviz separat de oferta” numai pentru un document distinct; numarul si data acestuia raman obligatorii impreuna.
Ciornele existente care contin un deviz pastreaza datele si afiseaza optiunea bifata.
Schimbarea optiunii invalideaza previzualizarea. Contractele deja emise raman nemodificate.

Oferta trebuie emisa sau incarcata in dosar; preluarea referintei nu creeaza si nu ataseaza automat un document lipsa.
Sablonul instalat este adaptat la generare pentru formularea „oferta/devizul tehnico-economic”.
