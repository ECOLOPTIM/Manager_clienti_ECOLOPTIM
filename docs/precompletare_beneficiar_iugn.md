# Precompletarea beneficiarului

La deschiderea unui contract nou sunt preluate datele din fisa clientului; datele lipsa sunt recuperate din cea mai recenta ciorna sau din contractul emis al aceluiasi client.
Ciorna lucrarii curente are prioritate, inclusiv campurile sterse intentionat. O adresa sau un act de identitate actualizat partial in fisa clientului nu este completat cu fragmente din documentele vechi.
Se reutilizeaza numai identificarea, domiciliul/sediul si contactele beneficiarului. Nu se copiaza CNP, adresa lucrarii, corespondenta speciala, numerele documentelor, sumele, semnatura sau etapele altei lucrari.
Precompletarea nu modifica fisa clientului sau contractele emise; datele sunt revizuite in formular si salvate in ciorna lucrarii noi.
