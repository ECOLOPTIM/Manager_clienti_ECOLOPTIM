# Previzualizare simplificata a contractului IUGN

CNP nu mai este solicitat in formularul contractului, preluat din client, salvat in ciorne noi sau inclus in contextul documentului emis. Generatorul elimina rubrica si din sabloanele mai vechi deja instalate. Datele istorice din fisa clientului si contractele deja emise nu se rescriu prin aceasta schimbare.

Descrierea porneste de la tipul lucrarii daca lipseste o descriere proprie. Pentru avize cu valoare zero se completeaza automat textul privind neincluderea avizelor. Documentele pentru detectoare au implicit mentiunea Nu este cazul, care se modifica daca beneficiarul furnizeaza echipamente si documente. Aceste texte raman editabile.

Lipsa configuratiei GDPR a firmei nu impiedica previzualizarea. Rubricile lipsa sunt marcate NECONFIGURAT - numai pentru previzualizare. Lipsa numarului devizului este marcata NECOMPLETAT, iar data este provizoriu cea a contractului. Nu se inventeaza perioade de pastrare sau referinte ale unor documente reale si aceste completari provizorii nu se salveaza in Date generale ori in ciorna.

Emiterea finala pastreaza validarea completa: devizul si configuratia firmei/GDPR trebuie completate cu date reale. Previzualizarea nu confirma etapa Contract emis, nu aloca numar si nu salveaza un document final. Clientul si pretul, transele si conditiile fluxului se verifica in continuare.

Mesajele de eroare din formular afiseaza denumirile rubricilor pentru operator, nu identificatorii interni ai campurilor. Nu este necesara reinstalarea sablonului pentru eliminarea rubricii CNP din documentele generate.
